#### What I'm building

**[Atelier](https://github.com/yannickYamo/atelier)**
Turn expert judgment into an AI skill you own.

Give it work an expert considers excellent. It infers the standards behind that work, the expert
ratifies what's actually true, and it compiles the result into a portable skill. The expert owns what
good means. The tool owns the job of reproducing it, and can improve *how* it does that without ever
changing *what* was approved.

Built because I kept hitting the same wall. I could give a model perfect context and still get variance.
Knowing what information to feed a model turns out to be a different problem from controlling what
standard it reproduces.

**[skills](https://github.com/yannickYamo/skills)**
AI skills for Claude Code. Product marketing, strategy, GTM.

**StratOS** *(private)*
A product and GTM operating system. 39 skills, a validation pipeline, and a governance layer that makes
sure the standard a skill claims to serve is the one the model actually receives.

#### How I think about this

Models are getting cheaper at everything objective. What stays scarce is the part that was always
hardest to write down: what to emphasize, what to ignore, what feels wrong despite looking reasonable,
when to break the framework, which technically correct answer you'd never ship.

Most of my work is some version of turning that invisible layer into infrastructure.

I write about product, AI systems, energy, and what building hardware teaches you about building
anything.
